#  License Plate Detection & Recognition (YOLO + CNN)

سیستم تشخیص و خواندن پلاک خودرو با ترکیب YOLO (برای مکان‌یابی پلاک) و یک شبکه‌ی کانولوشنی (برای شناسایی تک‌تک کاراکترها).

## معرفی پروژه

این پروژه یک پایپلاین کامل برای تشخیص پلاک خودرو در تصویر و خواندن متن آن (ترکیب حروف و اعداد) ارائه می‌دهد:

1. مکان‌یابی پلاک در تصویر خودرو با مدل YOLO
2. برش (Crop) ناحیه‌ی پلاک از تصویر اصلی
3. پیش‌پردازش تصویر پلاک (بزرگ‌نمایی، حذف نویز، بهبود کنتراست)
4. جداسازی تک‌تک کاراکترهای پلاک با پردازش تصویر (Contour Detection)
5. شناسایی هر کاراکتر با یک مدل CNN آموزش‌دیده روی دیتاست EMNIST
6. بازسازی متن کامل پلاک از کاراکترهای شناسایی‌شده

##  معماری پایپلاین

### ۱. تشخیص پلاک (Detection)
- مدل **YOLO** با وزن‌های سفارشی (`best.pt`) که برای تشخیص پلاک train شده است
- خروجی: مختصات bounding box محل پلاک در تصویر

### ۲. پیش‌پردازش تصویر پلاک
- تبدیل به grayscale و بزرگ‌نمایی (scale factor ۶) با interpolation از نوع Cubic
- کاهش نویز با Gaussian Blur
- بهبود کنتراست موضعی با CLAHE (Contrast Limited Adaptive Histogram Equalization)
- حذف نویز باینری و پاک‌سازی پس‌زمینه

### ۳. جداسازی کاراکترها
- باینری‌سازی تصویر با Otsu Thresholding
- شناسایی کانتورهای هر کاراکتر و فیلتر کردن بر اساس نسبت مساحت و ارتفاع

### ۴. شناسایی کاراکترها (Recognition)
مدل CNN با معماری زیر روی دیتاست **EMNIST Balanced** (۴۷ کلاس: ارقام ۰-۹ + حروف بزرگ و کوچک لاتین) آموزش دیده است:

| لایه | جزئیات |
|---|---|
| Conv2D | ۳۲ فیلتر، کرنل ۳×۳، ReLU |
| MaxPooling2D | ۲×۲ |
| Conv2D | ۶۴ فیلتر، کرنل ۳×۳، ReLU |
| MaxPooling2D | ۲×۲ |
| Flatten + Dense | ۱۲۸ نورون، ReLU |
| خروجی | ۴۷ کلاس، Softmax |
| تعداد کل پارامترها | ۲۲۹,۸۰۷ (~۸۹۸ KB) |

##  دیتاست‌ها

- **EMNIST Balanced** (برای آموزش شناسایی کاراکتر): ۱۱۲,۸۰۰ نمونه‌ی train و ۱۸,۸۰۰ نمونه‌ی test، شامل ۴۷ کلاس (ارقام و حروف)
- دیتاست تصاویر پلاک برای آموزش YOLO (فرآیند train روی Colab انجام شده؛ کد آماده‌سازی داده در نوت‌بوک به‌صورت کامنت موجود است)
